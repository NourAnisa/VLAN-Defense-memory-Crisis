SKENARIO 2 - CLOUD VIRTUALIZATION Host Physical: 16 GB RAM

Memory Overcommit Crisis

Tantangan lingkungan Proxmox VE / VMware ESXi. Tiga Virtual Machine (Web Nginx, DB Postgres, AI Worker) meminta total 30 GB memori virtual pada server fisik yang hanya berkapasitas 16 GB RAM. Kendalikan virtio-ballooning, aktifkan Kernel Samepage Merging (KSM), dan atur paging ZRAM/Swap secara dinamis agar VM tidak terkena Kernel Panic OOM.

VM 101 (Nginx): Burst Traffic Wave 1 - 4.5 GB
VM 102 (DB Postgres): Heavy Query Wave 2 - 7.8 GB
VM 103 (AI Worker): LLM Inference Wave 3 - 11.5 GB
