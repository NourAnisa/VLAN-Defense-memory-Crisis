SKENARIO 2: VIRTUALIZATION Host: 16 GB RAM

Memory Overcommit Crisis

Simulasi lingkungan Proxmox VE 8.1 / VMware ESXi. Tiga Virtual Machine menuntut 30 GB memori virtual pada server fisik 16 GB. Kendalikan virtio-ballooning dinamis dan aktifkan KSM untuk mencegah pemicuan Linux OOM-Killer.

Rasio Overcommit: 1.87x (30 GB / 16 GB)
Mekanisme KSM: Hemat ~1.8 GB RAM
Beban Kerja: 5 Gelombang Stress-ng

Dual Terminal: kubectl & oc Support
